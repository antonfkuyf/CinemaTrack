# CinemaTrack

## О проекте

Проект представляет собой информационную систему для автоматизации работы кинотеатра («CinemaTrack»). Система предназначена для управления репертуаром, учёта сеансов, продажи и возврата билетов, а также контроля занятости зрительских мест и формирования отчётности.

## Принцип работы системы

Программа построена по трёхуровневой архитектуре:

- **Слой пользовательского интерфейса** — обеспечивает взаимодействие с пользователем (консольный или веб-интерфейс).
- **Слой бизнес-логики** — выполняет проверку доступности мест, расчёт стоимости билетов, авторизацию пользователей и управление состоянием сеансов.
- **Слой данных** — хранит информацию о фильмах, залах, сеансах, местах, билетах и пользователях.

В системе предусмотрено разграничение прав по ролям:

- **Зритель** — выполняет самостоятельную регистрацию, авторизацию, просмотр афиши, выбор места в зале, покупку билетов онлайн и просмотр истории покупок в личном кабинете.
- **Администратор** — авторизуется в системе, управляет репертуаром (добавление, изменение и удаление фильмов), создаёт сеансы, оформляет продажу и возврат билетов через кассу, просматривает статистику продаж, а также регистрирует новых администраторов и зрителей.
